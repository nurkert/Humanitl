# Security policy

Humanitl is a security tool, so reports about it matter. Please do **not** open a public issue for
a vulnerability.

Contact: see GitHub security advisories for this repository (private vulnerability reporting).

Report form: <https://github.com/nurkert/Humanitl/security/advisories/new>

- Include the affected version, the sandbox profile (`humanitl sandbox argv`) and a minimal
  reproduction.
- Acknowledgement within 72 hours, assessment within seven days.
- Coordinated disclosure after 90 days or when a fix is available, whichever comes first.
- There is no bug bounty.

Supported versions: the latest release only.

The full security argument, its limits and how to check it yourself are in
[`docs/SECURITY.md`](docs/SECURITY.md); the attacker model is in
[`docs/THREAT-MODEL.md`](docs/THREAT-MODEL.md).
